# A1：算法与公共接口 v1

冻结日期：2026-10-24。此版本作为 A 的交接基线，B/C 尚未人工确认。仅覆盖方形网格、double、零 Dirichlet 边界、零初值；MPI 及 OpenMP 实现由 B/C 完成。

## 数学定义

单位正方形上求解 `-Δu=f`。全局每方向 N 个内点，`h=1/(N+1)`。内点坐标 `(x,y)=(j*h,i*h)`，`i,j=1..N`；物理边界索引为 0、N+1。

```text
(A_h u)[i,j] = (4u[i,j]-u[i-1,j]-u[i+1,j]-u[i,j-1]-u[i,j+1]) / h²
u_new[i,j] = (u_old[i-1,j]+u_old[i+1,j]+u_old[i,j-1]+u_old[i,j+1]+h²f[i,j]) / 4
```

读旧缓冲、写新缓冲；一轮结束后只交换存储，不复制完整网格。所有物理边界保持精确的 0。空间复杂度 O(N²)，每轮更新与一次残差计算均为 O(N²)，K 轮总计算量 O(KN²)。串行同时存储当前解、下一轮解和右端，主存储约 `3*(N+2)²*sizeof(double)`。

## 右端与验证问题

1. `continuous-sine`：`u*=sin(πx)sin(πy)`，`f=2π²u*`。与 u* 的误差包含离散误差，充分收敛后随 h² 下降。
2. `discrete-sine`：同一 u*，`f_h=λ_h u*`，`λ_h=8 sin²(πh/2)/h²`。该正弦向量是离散算子的特征向量；代码用解析特征值生成右端，不复用残差 stencil，以增加验证独立性。
3. `zero`：`f=0,u*=0`，用于边界和初始已收敛情况。
4. 2026-10-27 新增 `discrete-mixed`：两个方向/频率不同的离散正弦模态，N>=3；定义、独立 oracle 和验证结果见 [A_1027 工具说明](A_1027_tools.md)。原三种问题及接口语义保持兼容。

离散正弦问题从零值开始，第 K 轮精确算术解为 `(1-ρ^K)u*`，`ρ=cos(πh)`。连续正弦问题充分收敛后的离散解为 `(2π²/λ_h)u*`。该公式为测试 oracle，不用于跳过实际迭代。

这些可控问题服务于验证和性能比较，不涉及真实数据结论。核心库可接收其他右端；当前 CLI 暴露上述四种。

## 行布局与内核

`Grid(global_n, local_rows, row_offset)` 使用 row-major 连续数组：

- `stride=N+2`，本地 `rows+2` 行，总元素 `(rows+2)*(N+2)`。
- 本地拥有行 `1..rows`；本地行 i 对应全局行 `row_offset+i`。
- `row_offset` 表示本子域之前的全局内点行数，从 0 开始。
- 本地第 0 行和 rows+1 行是 ghost 行；仅全局最上/最下子域对应物理边界。
- 所有行的第 0/N+1 列是物理边界；内点列为 1..N。
- 首版不支持零行子域；B 应拒绝 rank 数大于 N 的配置。
- `values.data()+i*stride` 指向第 i 行；MPI 数据类型/长度/邻居由 B 决定，不在 A 内核中硬编码。

`jacobi_rows(old,next,rhs,begin,end)` 对半开行区间 `[begin,end)` 更新，合法范围 `1<=begin<=end<=rows+1`；空区间合法。输出不能与 old/rhs 别名，不更新 halo/物理边界，不交换缓冲。

`residual_squared_rows` 返回该区间 `Σ(f-A_h u)²`，`squared_norm_rows` 返回 `Σu²`。B 必须先对局部平方和做全局 SUM，再开平方、计算范数比；不能平均局部相对残差。C 需要对平方和使用正确 reduction。

更新边界行前 old halo 必须有效；计算残差前**当前解**的 halo 必须有效。交换 old/new 后不得继续用上一轮 halo 计算当前残差。非阻塞发送未完成之前，不能修改或复用发送缓冲。单行子域的边界行只能更新一次。

## 停止规则

残差 `r=f-A_h u`。`rhs_l2>0` 时指标为 `||r||₂/||f||₂`；右端范数为 0 时使用绝对 L2 残差。CLI 标记 `residual_kind`，不能把后者误写成真正的相对值。

- `fixed`：恰好执行 K 轮，不因容差提前退出。K 可为 0。第 k、2k…轮和最终轮计算残差；到达最终轮且恰好是 k 的倍数时只计算一次。
- `converge`：先检查初值；满足阈值可在 0 轮停止。之后按相同检查间隔检查，在首次检查到指标 <= tol 时停止；最多执行 K 轮。K 必须为正。
- 收敛模式达到上限未满足容差，输出 JSON 和退出码 2；不伪装成已收敛。
- 程序最后在计时外重新计算残差及已知解误差，确保包括 K=0 的运行也有诊断。
- `timed_residual_checks` 只计入计时内检查，包含收敛模式初始检查，不含最后的额外诊断。

残差是方程残差，不使用 `||u_new-u_old||` 代替。改变 check-every 会改变开销及实际停止轮数，正式对比应固定并记录。

## 计时与结果 schema v1

V0 使用 `std::chrono::steady_clock` 墙钟。计时前完成分配、初始化和右端范数；计时包括更新、交换、计划内残差检查；计时后执行完整场诊断、序列化与 CSV 输出。

MPI 版本应对齐相同计算范围，计时包含必要 halo 和全局归约，报告各 rank 求解耗时最大值；不能把串行无通信时间与并行不含通信时间混为完整求解速度。每轮不额外加计时用 barrier。

stdout JSON 一条运行一个对象，主要字段在 `include/config.hpp` 定义。`n` 对应实验总表的 `nx=ny=n`；V0 的 ranks/threads_per_rank 均为 1。`converged` 只反映残差达标，并不等于独立验证通过。集群/job/commit/编译选项由 C 的后续实验采集层补齐，当前程序不填造这些信息。

`exact_relative_l2_error` 对正弦解是误差 L2/已知解 L2；零解采用绝对误差 L2。`seconds_per_iteration=0` 表示零次更新，不作为性能样本。

## 验证标准

- 小网格串并行固定步数比较：最大逐点误差满足 `|a-b|<=1e-10+1e-10|a|`，并报告相对 L2 误差；边界必须保持零。
- 本地串行验证用更严格的独立 oracle：稠密参考绝对误差 <1e-12；离散模态逐点误差 <2e-14。
- 收敛离散已知解：残差 <=1e-11，最大解误差 <2e-11（N=15 测试）。
- 连续已知解：N=7/15/31，h 每次减半；求解残差 <=1e-11，最大误差比要求 3.9–4.1。
- 所有 MPI/线程组合的验证仍待 B/C 交付；局部 slab 模拟测试不是实际 MPI 验证。
