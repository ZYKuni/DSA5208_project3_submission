## 算法、验证和限制审阅

核对了 -Δu=f 的符号、五点差分 Jacobi 更新、旧新缓冲交换、每轮 O(N²)/总 O(KN²) 和三数组空间估计。连续正弦误差包含二阶离散误差，离散 mixed/sine 已知解用于隔离实现误差；零 RHS 采用绝对范数。报告计时范围与 solver_mpi.cpp 一致：初始化/RHS 范数不计入，迭代、halo 与计划内归约计入，最终诊断/回收不计入。

Vanda 验证矩阵 294 与 MPI-only 124 的覆盖重叠，不相加为不同数学问题数。本轮扩展矩阵的新结果只归入本地/CI，报告仍引用实际 Vanda 的原始 294 记录。

单 rank 慢样本、仅单节点、固定重复次序、节点非整机独占、基线未固定单核、NUMA/频率未控制等限制均有披露。没有将约 1.7% 的通信差异解释为稳定收益，也没有跨节点或 GPU 实测声明。此次完整复算不构成新增集群性能实验。
